## Integradas

- Foto real horizontal de visita rural: 1286×965; buena para tarjeta y trabajo de campo.
- Foto real vertical GNSS: 724×965; adecuada para tarjeta, limitada para grandes banners.
- Foto real vertical de oficina: 544×965; útil para contacto, conviene reemplazarla por una toma nítida de 1600 px o mayor, frontal y sin obstáculos.
- Logo: extraído de 2.png, sin redibujar la marca. Solicitar original SVG, PDF vectorial o PNG transparente de alta resolución para eliminar fondo y mejorar nitidez.
- Arquitectura y obra: dos apoyos generados, 1536×1024 originales, exportados a WebP 480/960/1440 px. No se presentan como trabajos realizados.

2.png y las tarjetas de presentación se usan como referencia de identidad; no como carteles completos en la web. Sus textos pequeños y proporciones perjudican la lectura móvil. Recomendación: horizontal 2400×1600 o mayor para originales, vertical 1600×2000 para retratos; luz natural, cámara recta, sin filtros ni textos impresos sobre la imagen. Guardar originales fuera de dist; exportar WebP con calidad 80–86, tamaños 480/960/1440 según destino. Alt debe describir lo que se ve, sin afirmar un resultado no comprobado. Mantener nombres descriptivos y sin datos de clientes.

Para casos reales aún faltan título, distrito, fecha, alcance, entregables y resultado. La web muestra únicamente dos fotografías de trabajo de campo, sin adjudicarles ubicación, fecha, cliente ni éxito registral.
