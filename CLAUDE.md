# CLAUDE.md

Este repositorio es la web https://conplanos.com. Las reglas completas están en `AGENTS.md`; aquí solo va el procedimiento para Claude.

## Antes de modificar

- Leer `AGENTS.md`.
- Leer `docs/SEO_HANDOFF.md`.
- Leer `docs/SEO_DECISIONS.md`.

Consultar `docs/SEO_WORKLOG.md` cuando haga falta historial.

## Antes de terminar

- Ejecutar las pruebas disponibles (`npm run build`, `npm run check`, `npm test`) y no declarar las que no se pudieron ejecutar.
- Actualizar `docs/SEO_HANDOFF.md`.
- Añadir entrada a `docs/SEO_WORKLOG.md`.
- Actualizar `docs/SEO_DECISIONS.md` si corresponde.
- Indicar el commit resultante y el siguiente paso.

`main` es producción: no hacer push a `main` ni merge sin aprobación expresa.
